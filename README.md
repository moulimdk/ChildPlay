# 🌱 Little Learner

A growing collection of bilingual learning activities built for my son — and shared with anyone who wants to use them. As he grows, this site grows with him.

## 🧒 About

This is a personal project that started as a way to make learning fun and accessible for my toddler. Each section is added when he's ready for it, so the site evolves alongside his curiosity. All activities are available in both **English** and **Bengali (বাংলা)** to support bilingual learning at home, with room to add more languages as he picks up interest in them.

## ✨ Activities

| # | Activity | Focus | Age Range | Status |
|---|----------|-------|-----------|--------|
| 1 | **Letters** / **অক্ষর** | Letter recognition, sounds, tracing | Toddler+ | 🟡 In progress |
| 2 | **Numbers & Counting** / **সংখ্যা ও গণনা** | Number recognition, counting, basic quantities | Preschool+ | 🟡 In progress |
| 3 | **Spelling** / **বানান** | Word building, simple spelling, phonics | Early elementary+ | ⚪ Planned |

More activities will be added as he grows. Difficulty also adapts: the Letters page he uses at age 2 will look different than the version he uses at 4.

## 🌍 Languages

## 🚀 Viewing the Site

The site is hosted on **GitHub Pages**:
👉 [https://moulimdk.github.io/little-learner](https://moulimdk.github.io/little-learner)

To run locally, clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/yourusername/little-learner.git
cd little-learner
# Open index.html directly, or serve with a simple HTTP server:
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
